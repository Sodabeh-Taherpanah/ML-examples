Handle missing Values

  • Here We handled missing values by filling with decent common values, median, or forward-fill.
  • Check format of datetime columns.
  • Use the next available valid value for some miss value.(Backfill)
  • Use pd.NaT for missing timestamps where data should explicitly indicate "not available" it is better to assume an incorrect value(order_delivered_customer_date).

def color_cells(val):
    if isinstance(val, (int, float)):

        if val > 50:
            color = 'background-color: darkorange; color: black'
        elif val > 30:
            color = 'background-color: orange; color: black'
        else:
            color = 'background-color: lightyellow; color: black'
        return color
    else:
        return ''

def convertTimeToMinutes(time_str):
    try:

        time_delta = pd.to_timedelta(time_str)
        return round(time_delta.total_seconds()/60)
    except Exception as e:
        return None
